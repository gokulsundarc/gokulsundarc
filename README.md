## 🚀 Featured Projects

### 🛡️ [Wazuh SOC Home Lab](https://github.com/gokulsundarc/Wazuh-SOC-lab)

> A fully functional SOC environment simulating real-world cyber attacks across **3 attack vectors** with automated detection and response.

| Feature | Details |
|---|---|
| ⚔️ **Attacks Simulated** | SSH Brute Force, FTP Brute Force, HTTP Attacks, Port Scanning |
| 🔍 **Detection** | Custom Wazuh rules mapped to MITRE ATT&CK (T1110, T1083, T1595, T1190) |
| 🛡️ **Auto Response** | Attacker IP auto-blocked via nftables/iptables — zero manual action |
| 📱 **Telegram Bot** | Real-time alerts + interactive commands (/status, /alerts, /blocked, /clear) |
| 🔑 **Key Finding** | Documented iptables vs nftables architecture on Ubuntu 24.04 |
